About

What is Sudoku?

Sudoku is a 9 by 9 number puzzle. The goal is to fill every empty cell using numbers 1 to 9 so that no number repeats in any row, column, or 3 by 3 box.

Recursion

Recursion means a function calls itself to solve a smaller part of the same problem. In Sudoku, the solver fills one empty cell and then calls itself to fill the next cell.

Backtracking

Backtracking tries one possible value at a time. If a value later causes a problem, the program removes it and tries another value.

Generation

The generator starts with an empty board, fills it recursively using shuffled numbers, stores the solved board, and removes cells based on difficulty.

Solving

The solver finds an empty cell, checks numbers 1 to 9 using isSafe, places a valid number, and continues recursively until the board is solved.

DSA Concepts

The project demonstrates 2D arrays, functions, classes, objects, recursion, backtracking, vectors, random shuffling, and simple modular programming.
